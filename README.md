# Zomato-Sample-Data-Analysis
This project explores the Zomato dataset to uncover insights about restaurants, cuisines, locations, costs, and customer preferences.
The analysis was done in Python using pandas, matplotlib, and seaborn.

## The goal of this project is to:

- Understand restaurant distribution across locations.

- Identify the most popular cuisines.

- Compare budget-friendly vs. premium restaurants.

- Explore the relationship between cost and votes.

## Tools & Libraries Used

- Python 🐍

- Pandas → Data cleaning & manipulation

- Matplotlib / Seaborn → Data visualization

## Dataset Used:
https://www.kaggle.com/datasets/shrutimehta/zomato-restaurants-data


## Key Analysis & Insights

✔️ Top 10 locations with the most restaurants

✔️ Most popular cuisines across restaurants

✔️ Budget restaurants (Cost ≤ 500) distribution

✔️ Comparison of average cost vs. votes by restaurant type

✔️ Gradient heatmaps to highlight top categories
